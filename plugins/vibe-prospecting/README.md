# Vibe Prospecting

Find leads and B2B contact data inside Cursor.

The plugin ships twelve skills: list building, account contacts, company enrichment, contact enrichment, account research, competitor research, meeting prep, lookalike accounts, market sizing, lead scoring, talent sourcing, and list cleanup.

MCP server: `https://mcp-cursor.vibeprospecting.ai/mcp`. Cursor starts OAuth on first use.
